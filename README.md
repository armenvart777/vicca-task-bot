# vicca-task-bot

Маркетплейс задач для инфлюенсеров в Telegram. Три роли: администратор, инфлюенсер, заказчик. Полный цикл от создания задачи до верификации выполнения.

## Возможности

- мультиролевая система (admin / influencer / customer)
- создание и управление задачами
- подача заявок, одобрение, отклонение
- верификация выполнения с доказательствами
- платежи и отчёты
- middleware для авторизации
- FSM для пошагового ввода данных

## Архитектура

```
vicca_bot/
├── bot.py           # точка входа
├── config.py        # конфигурация
├── handlers/        # обработчики по ролям
├── services/        # бизнес-логика
├── keyboards/       # клавиатуры
├── middlewares/      # авторизация, логирование
├── filters/         # кастомные фильтры
├── states/          # FSM состояния
├── db/              # модели и запросы
└── utils/           # утилиты
```

## Стек

Python 3.10+, aiogram 3, PostgreSQL, asyncpg

## Запуск

```
pip install -r requirements.txt
cp .env.example .env
python bot.py
```
