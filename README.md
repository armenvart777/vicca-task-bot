# Vicca Task Bot

Структура Telegram-бота для задач между заказчиками и авторами контента. Код разделен по ролям: заказчик, автор и администратор.

- `handlers/customer/` и `handlers/blogger/` показывают, как разнесены сценарии задач и отчетов.
- `states/` содержит состояния пошаговых форм.
- `services/escrow.py` показывает интерфейс резервирования, выплаты и возврата. Эти функции оставлены заглушками.

## Запуск

Публичный снимок подходит для просмотра структуры проекта. Он не запускается как бот: `bot.py` импортирует отсутствующий модуль `db.engine`, а функция `main()` и значительная часть обработчиков оставлены заглушками.
